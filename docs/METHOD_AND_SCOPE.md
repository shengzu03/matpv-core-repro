# 核心方法与范围

本包从已有冻结实现整理，不把已有算法重新命名为原创算法。MAT-PV为Memory-Augmented Trees with Pairwise Verification，表示完整流程。TON版本使用原TON模型文件；RT与CIC39使用原外部参数化版本，避免将外部版的边缘防护改动默默引入TON。

## 固定参数

| 环节 | 冻结实现 |
| --- | --- |
| 普通树与主树 | ExtraTrees 300棵、max_features=1.0、balanced、min_samples_leaf=1、bootstrap=False、单线程、种子加4123 |
| 前50条获取 | 源树教师；五个盲分层各报警8条、不报警2条；缺额按原规则补 |
| 距离空间 | 源集拟合中位数与IQR，下限0.25，裁剪至[-10,10] |
| 图纠错 | 池内10近邻、无向化、行归一化；5折分组OOF残差；0.8传播50轮，锚点固定 |
| 后20条获取 | 图纠错概率熵排序；从未触及分组取实际代表记录；固定并列次序 |
| 高斯记忆 | 仅源集加前50标签中的攻击记录；类协方差权重n/(n+1)，其余任务协方差，加单位阵 |
| 二分类SVM | RBF、C=1、balanced、gamma=scale、tol=0.001、max_iter=200000；使用源加全部70条 |
| 成对SVM | 目标类对原其他攻击类，共享二分类gamma；严格margin>0通过 |
| 报警阈值 | 2,000条历史正常分数的99%顺序统计量；严格大于阈值才报警 |
| 补检阈值 | 100条保护类验证记录约束；不使用测试标签调阈值 |

五个盲分层是选样分层，不是联邦客户端，不涉及通信、聚合或联邦训练。

## 决策范围

图阶段之后，下游补检保留原正常、保护类和原目标类判断；记忆已接受的目标候选也保留。二分类仅在其他攻击类别中补认目标类。条件复核只检查二分类新提出的候选，缺对应成对头时按原实现放行。缺目标正例时不制造正例，相关头按原规则停用。

这些保护关系只相对于同一流程的图阶段输入，不等于最终模型相对独立tree70的报警和保护类预测完全相同，因为二者的主树训练标签位置不同。

## 评价定义

rare_f1是预先指定保护类与目标类F1的算术平均，不是全部类别宏F1，也不一定代表数据中所有最稀有类别。正确类别检出率要求名称正确；任意攻击报警率只要求判为非正常。二分类补认不提供新的完整概率分布，AUC等报警指标仍使用图阶段1−p(normal)，不伪造SVM后的多类概率。

## 文件移植

provenance/source_manifest.json记录原文件哈希与打包位置。算法文件仅调整相对导入和高斯纯函数的引用；数据准备仅调整输入路径和盘符限制；新的命令行、缓存管理、结果汇总与完整性检查是复现包装层。原档案未改写，包内新文件哈希也不冒充旧冻结哈希。

reference保存全部七种配置的历史结果，包含未获提升的RT与低绝对表现的CIC39，未按有利结果挑选配置或重复。本包没有重新证明各模块独立贡献，也未补做论文已接受的证据缺口。
